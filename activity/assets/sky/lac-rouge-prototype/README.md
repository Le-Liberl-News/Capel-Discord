Prototype local « Le lac des hortensias ».

- `eau-rouge.png` : palette rouge de l’eau native `T02O1703.png`.
- `reflets-rouges.png` : palette rouge des reflets natifs `T02O1803.png`.
- `hortensias-blanc.png` / `hortensias-violet.png` : texture native `T153nk10.png`, bouquets réassemblés par copier/coller de ses propres pétales puis recolorés. Dimensions natives 256 × 256 et transparence conservées.
- `*-halo.png` : masque diffus des pétales, pour une émission douce occluse par les murs.

Retouches déterministes dans `tools/map-editor/lake-textures.py`. Aucun asset généré par IA. Ces massifs sont une adaptation visuelle de la plante native, pas l’extraction d’un modèle d’hortensia identifié dans les jeux.
